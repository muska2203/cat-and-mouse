# Идеи и бэклог

Сюда складываем идеи по мере появления. Приоритет: **высокий** / **низкий** (при необходимости добавим средний).

---

## Записи

### Миникарта
- **Приоритет:** низкий
- Краткая карта уровня (обзор лабиринта, цель, игрок).

### Масштаб игры
- **Приоритет:** низкий
- Поиграться с масштабом отображения (zoom, размер тайла, UI под разные DPI).

### Скиллы для посохов при активном посохе
- **Приоритет:** высокий
- У посохов — активируемые скилы, доступные только когда посох экипирован / «активен» по правилам игры.
- **Проверить (ревью кода):** скиллы предметов (сейчас в дизайне — прежде всего оружие) должны попадать в доступный список скиллов только когда предмет **в слоте** экипировки; убедиться, что текущая реализация это соблюдает (в UI слева сейчас выводятся только изученные скиллы из `getCoreSkillDefs`, без отдельной ветки «скиллы экипированного оружия»).

### Урон врагам (сложность)
- **Приоритет:** высокий
- Поднять урон у врагов, чтобы бой ощущался чуть сложнее.

### Геймплей через «интеллект»
- **Приоритет:** (не задан — уточнить)
- Придумать/проработать геймплейные особенности с опорой на ИИ (например: подсказки, процедурные события, поведение врагов, генерация контента — уточнить направление при записи в задачу).
