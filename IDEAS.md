## Записи

### Миникарта
- **Приоритет:** низкий
- Краткая карта уровня (обзор лабиринта, цель, игрок).

### Масштаб игры
- **Приоритет:** низкий
- Доработать масштабирование интерфейса: сейчас есть базовый zoom/подстройка размера тайла канваса, но нет отдельной настройки масштаба UI-панелей и типографики под разные DPI.

### Расширить скиллы посохов
- **Приоритет:** высокий
- Текущая механика уже корректная: скиллы предмета доступны только при экипированном источнике.
- Идея: расширить контент посохов (больше вариантов активных скиллов/синергий), а не чинить условие активации.

### Урон врагам (сложность)
- **Приоритет:** высокий
- Поднять урон у врагов, чтобы бой ощущался чуть сложнее.

### Геймплей через «интеллект»
- **Приоритет:** (не задан — уточнить)
- Придумать/проработать геймплейные особенности с опорой на ИИ (например: подсказки, процедурные события, поведение врагов, генерация контента — уточнить направление при записи в задачу).

## Расхождения с README (ревью реализации)

### Выбор сложности при старте забега
- **Приоритет:** низкий
- В концепте есть пункт «сложность (в разработке)», но в текущем экране создания персонажа выбор сложности отсутствует.
- Задача: добавить явный выбор сложности (или убрать ожидание из README до реализации).

### Лут на земле при генерации уровня
- **Приоритет:** средний
- В концепте заявлен как объект уровня, но сейчас на старте уровня лут не раскладывается (обычно появляется из сундуков).
- Задача: либо добавить стартовый спавн лута, либо уточнить формулировку концепта.

### Ловушки и временные зоны как часть генерации уровня
- **Приоритет:** средний
- В концепте описаны как элементы уровня, но сейчас в основном появляются от действий игрока (расходники/эффекты), а не заранее.
- Задача: решить, нужны ли прегенерированные ловушки/облака в самом уровне.

### Боссы в итоговом экране без отдельной системы боссов
- **Приоритет:** средний
- На экране итогов есть секция «Побежденные боссы», при этом отдельной босс-механики в боевой/спавн-логике нет.
- Задача: либо реализовать боссов, либо скрыть/переформулировать блок до фактической поддержки.
