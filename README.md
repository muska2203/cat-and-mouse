# Cat-and-Mouse

Мини-игра про мышку в лабиринте: сражения с котами, лут из сундуков и прохождение уровней.

## Правила геймплея (ориентир для разработки)

Этот раздел фиксирует базовые правила игры. При добавлении новых механик они не должны ломать эти правила без отдельного решения.

### 1) Создание персонажа

Перед стартом забега персонаж собирается из базовых выборов:
- внешность;
- характеристики;
- стартовая экипировка;
- сложность (в разработке).

### 2) Пошаговая модель

Игра работает в цикле из двух фаз:
- ход игрока;
- ход окружения.

Текущее боевое правило в реализации:
- одно успешное действие игрока завершает его фазу и запускает фазу окружения;
- окружение после этого отрабатывает свои действия и возвращает ход игроку.

Целевая модель (в разработке):
- ограниченные очки действий у игрока и у объектов окружения в рамках одного хода.

### 3) Правила фазы игрока

В фазе игрока персонаж может выполнить доступное действие или пропустить ход. Действия, которые считаются успешными и завершают фазу:
- шаг/атака при движении;
- применение скилла;
- применение расходника;
- установка ловушки.

### 4) Правила фазы окружения

В фазе окружения каждый активный объект окружения выполняет действия по своей логике:
- атака, если цель рядом;
- перемещение к цели, если атака невозможна;
- применение статусов и периодических эффектов, если они есть.

Текущее ограничение в реализации:
- объекты действуют только если находятся в открытой (разведанной) зоне карты.

### 5) Прогрессия забега

Игрок проходит уровни подземелья последовательно:
- достигает выходной клетки;
- переходит на следующий уровень;
- после финального уровня получает победу.

На уровнях размещаются:
- противники;
- сундуки;
- лут на земле;
- ловушки и временные зоны эффектов.

Случайные/сценарные события (босс, торговец, кузнец и т.д.) — в разработке.

### 6) Ресурсы персонажа

Базовые ресурсы забега:
- HP;
- MP;
- инвентарь (экипировка и расходники).

Правило ресурса:
- HP и MP не восстанавливаются автоматически между ходами;
- восстановление HP и MP доступно только через расходники.

Следствие для билдообразования:
- билды проектируются вокруг управления ресурсами и темпа боя (дистанционный урон, контроль, burst ближнего боя, урон по площади, выживаемость, гибриды).

### 7) Основные механики, уже входящие в правила игры

Ниже перечислены реализованные механики, которые считаются частью базового геймплея.

- Система экипировки и инвентаря:
  - предметы экипируются по слотам;
  - лут подбирается с клетки;
  - сундуки генерируют предметы по редкости.
- Базовый ближний бой:
  - урон зависит от оружия и характеристик;
  - есть критический удар и множители урона.
- Скиллы персонажа:
  - есть мана-стоимость;
  - есть проверка валидной цели;
  - перезарядки нет, повторное использование ограничено только ресурсами и условиями цели.
- Скиллы, привязанные к экипировке:
  - набор скиллов зависит от типа/подтипа предмета;
  - уровень скилла зависит от редкости предмета.
- Расходники:
  - восстановление HP/MP;
  - временный бафф на следующий удар;
  - предметы-ловушки для установки на поле.
- Эффекты и статусы:
  - оглушение;
  - яд;
  - периодическое лечение;
  - периодический урон.
- Временные объекты поля:
  - ловушки (одноразовые);
  - ядовитые облака с ограниченной длительностью.
- Пространственные правила:
  - туман войны и открытие карты вокруг игрока;
  - запрет недопустимого диагонального прохода через угол стены;
  - автопуть по открытым клеткам до выбранной цели.
